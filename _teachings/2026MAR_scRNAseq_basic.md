## Overview

Workshop series organised as part of the Bioinformatics Forum at Université Libre de Bruxelles (ULB), introducing practical analysis workflows for single-cell RNA-seq data using Python.

The workshops are based on PBMC single-cell datasets and focus on reproducible analysis workflows using Scanpy and related Python tools.

## Topics covered

- Quality control and filtering
- Normalisation and preprocessing
- Dimensionality reduction
- Clustering and annotation
- Differential gene expression analysis
- Gene regulatory network inference with SCENIC
- Downstream biological interpretation
